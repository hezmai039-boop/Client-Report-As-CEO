# ملحق داخلي — كيف تُترجَم الإجابات إلى إعداد المنصة
> *لا يُرسل للعميل — دليلك أنت عند التسجيل*

| السؤال | الحقل في المنصة | الأثر المباشر |
|---|---|---|
| ١ | `display_name` | يظهر في ترويسة كل تقرير |
| ٢ | ملف العميل | سياق للذكاء الاصطناعي |
| ٣ | `sector` | **يحدد القالب القطاعي** الذي يُبنى منه استبيانه ابتدائياً |
| ٤ | ملف العميل | يُمرَّر للذكاء الاصطناعي لفهم طبيعة النشاط |
| ٥ | — | **المؤشر الأهم**: اجعله أول سؤال في استبيانه وأبرز رقم في تقريره |
| ٦ | `QuestionDefinition` + `standard_field` | **يحدد أي حقول قياسية تُفعَّل** — ما لم يُختَر يُحذف من استبيانه |
| ٧ | `QuestionDefinition` بلا `standard_field` | سؤال حر يُضاف — تظهر إجابته نصياً في التقرير وتدخل التحليل |
| ٨ | ملف العميل | يُمرَّر للذكاء الاصطناعي لقياس التقدم نحو الهدف |
| ٩ | ملف العميل | يوجّه التوصيات لمعالجة تحدياته لا تحديات عامة |
| **١٠** | **`recommendation_preferences`** | **قيد إلزامي حرفي على مخرجات الذكاء الاصطناعي** — أهم حقل في الملف |
| ١١ | `email` | وجهة التقارير |
| ١٢ | ملف العميل | لمن تُرسل رسائل الواتساب والتذكيرات |
| ١٣ | — | أي تقارير تُولَّد له في الجدولة الدورية |
| ١٤ | — | رابط `/e/:token` أو مسار «استقبال واتساب» |
| ١٥ | ملف العميل | معيار نجاحكم بعد 30 يوماً — راجعه معه |

**تنبيه تشغيلي:** السؤالان ٦ و١٠ هما الأهم عملياً — السادس يبني استبيانه، والعاشر يحكم كل توصية يستلمها. لا تُسجّل عميلاً بإجابة ناقصة عليهما.
