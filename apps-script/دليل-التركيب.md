## الخطوة 1 — لصق الكود (دقيقة واحدة)

1. افتح مشروع Apps Script من الرابط أعلاه.
2. من القائمة اليسرى: **الملفات ← +  ← نص برمجي** (Script).
3. سمِّ الملف `automation` (بدون امتداد — يضيفه Google تلقائياً).
4. احذف المحتوى الافتراضي `function myFunction() {}` كاملاً.
5. الصق محتوى `apps-script/automation.gs` كاملاً.
6. **احفظ** (Ctrl+S).

> لا تحذف ولا تعدّل ملف `الرمز.gs` الحالي — هذا الملف مكمّل له، ولا يوجد أي تعارض في أسماء الدوال.

---

## الخطوة 2 — تشغيل التنصيب (دقيقتان)

1. من قائمة الدوال أعلى المحرر، اختر **`setupAutomation`**.
2. اضغط **تشغيل** (Run).
3. ستظهر نافذة صلاحيات:
   - اضغط **مراجعة الأذونات** ← اختر الحساب المالك.
   - إن ظهر تحذير "لم يتم التحقق من هذا التطبيق": اضغط **إعدادات متقدمة** ← **الانتقال إلى المشروع (غير آمن)** — هذا طبيعي لأن المشروع خاص بك وغير منشور.
   - اضغط **السماح**.

الصلاحيات المطلوبة ولماذا:

| الصلاحية | السبب |
|---|---|
| Spreadsheets | قراءة Master Sheet والكتابة في سجلات العملاء |
| Drive | إنشاء سجل العميل الجديد ونقله لمجلد المشروع |
| Gmail (إرسال) | البريد الترحيبي وتنبيهات الفحص اليومي |
| Triggers | تنصيب مشغّل النموذج والمشغّل اليومي |

## الخطوة 3 — التحقق من النتيجة (دقيقة واحدة)

بعد انتهاء التشغيل، افتح **سجل التنفيذ** (Execution log) أسفل المحرر. المتوقع أن ترى سطراً مثل:

```
تم التنصيب. صفوف نُقلت: 1 | عملاء غير مسجَّلين: مطعم بيت الطهي
```

### ما يعنيه ذلك

| النتيجة | التفسير |
|---|---|
| `صفوف نُقلت: 1` | ✅ بيانات **وجهة مستثمر** العالقة (45,000 ﷼ بتاريخ 2026/08/06) انتقلت أخيراً لسجله الفردي — المشكلة الأساسية حُلّت |
| `عملاء غير مسجَّلين: مطعم بيت الطهي` | ⚠️ متوقع — هذا العميل أرسل بيانات دون تسجيل. سيصلك بريد تنبيه أيضاً |
| `صفوف نُقلت: 0` | راجع أسماء الأوراق في ثوابت أعلى الملف (انظر "استكشاف الأخطاء") |

### تحقق بصري
افتح سجل "وجهة مستثمر" وتأكد أن ورقة **البيانات اليومية** لم تعد فارغة:

## الخطوة 4 — منع التقارير المكررة (دقيقة واحدة)

أرشيف "مطعم حاشي باشا" يحوي حالياً تقرير **05 أغسطس 2026** ثلاث مرات. لمنع تكرار ذلك:

في ملف `الرمز.gs`، ابحث عن دالة `generateAndSendReport` وأضف هذا السطر **قبل** استدعاء `sendReportEmail_` مباشرة:

```javascript
// حارس ضد التكرار — لا نرسل نفس التقرير مرتين
if (alreadySent_(clientSheetId, reportTypeLabel, periodLabel)) {
  Logger.log('تم تخطي إرسال مكرر: ' + clientName + ' — ' + periodLabel);
  return;
}
```

> استبدل `clientSheetId` / `reportTypeLabel` / `periodLabel` بأسماء المتغيرات الفعلية لديك في تلك الدالة (القيم المتوقعة: معرّف سجل العميل، `'التقرير اليومي'`، و`'05 أغسطس 2026'` مثلاً).

## إضافة عميل جديد بعد اليوم

في محرر Apps Script، عدّل دالة `quickAddClient` بالقيم المطلوبة وشغّلها:

```javascript
function quickAddClient() {
  return onboardNewClient_(
      'اسم العميل',          // يجب أن يطابق ما سيكتبه في النموذج حرفياً
      'client@example.com',  // بريده لاستلام التقارير
      'مطاعم',               // القطاع
      'الاسم الظاهر'         // كما سيظهر في التقرير
  );
}
```

تنفّذ الدالة تلقائياً: إنشاء السجل بأوراقه الثلاث ← نقله لمجلد المشروع ← بناء رابط نموذج معبّأ مسبقاً باسمه وقطاعه ← التسجيل في Master Sheet ← بريد ترحيبي للعميل ← تأكيد داخلي لك.

**الوقت: أقل من دقيقة، بدلاً من ساعة.**

### أول عميل تضيفه: مطعم بيت الطهي
الدالة مهيّأة له مسبقاً — أضف بريده فقط وشغّلها، ثم شغّل `routeFormResponses_` لاسترجاع بياناته العالقة (6,500 ﷼، 80 طلب).

## استكشاف الأخطاء

| العَرَض | السبب المرجّح | الحل |
|---|---|---|
| `صفوف نُقلت: 0` رغم وجود بيانات | اسم ورقة مختلف عن الثوابت | افتح سجل عميل وتحقق من اسم تبويب البيانات، ثم عدّل `TAB_CLIENT_DAILY` أعلى الملف |
| `Cannot read property 'getDataRange'` | ورقة مفقودة في سجل عميل | الكود ينشئها تلقائياً؛ إن تكرر الخطأ تحقق من `TAB_CLIENTS` و`TAB_SETTINGS` |
| بيانات عميل لا تُنقل أبداً | اسمه في النموذج لا يطابق ورقة العملاء **حرفياً** | وحّد الاسم، أو استخدم الرابط المعبّأ مسبقاً الذي تولّده `onboardNewClient_` (يمنع الخطأ من أصله) |
| لا تصل تنبيهات البريد | `OWNER_EMAIL` خاطئ في ورقة الإعدادات | القيمة الحالية: `hezmai039@gmail.com` — تأكد أنها صحيحة |
| `You do not have permission` | تسجيل دخول بحساب غير المالك | سجّل الدخول بـ hezmai425@gmail.com |

## ملاحظة على أسماء الأوراق

أسماء أوراق السجل الفردي (`البيانات اليومية` / `أرشيف التقارير` / `ملف العميل`) مأخوذة من توثيق المنصة ولم يمكن التحقق منها برمجياً. إن اختلف اسم فعلي، عدّل الثابت المقابل في أعلى `automation.gs`. الكود آمن في الحالتين: ينشئ الورقة بالرؤوس الصحيحة إن لم يجدها بدل أن يتوقف بخطأ.
